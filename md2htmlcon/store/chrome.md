# MD2HTML Converter

Short description: Convert Markdown/HTML with advanced MD/HTML editors, live preview, pages, selections, and downloads.

Long description: MD2HTML Converter for Chrome lets users convert selected page content, full webpages, raw Markdown pages, or pasted snippets. It includes a polished popup and side panel with advanced Markdown and HTML editors, live sanitized preview, diff tools, copy actions, and downloads.

Features:

- Convert Markdown to HTML
- Convert HTML to Markdown
- Convert selected text with a context menu
- Convert the current page
- Pull the current page with exact-origin permission prompts
- Mouse Reader for click-to-capture page elements
- Detect raw Markdown pages
- Paste Markdown or HTML
- Advanced Markdown and HTML editors with snippet insert tools
- Live sanitized preview for converted output
- Inline and side-by-side diff views
- Copy source, copy output, reset edits, and swap direction
- Download `.html`, `.md`, `.txt`, `.diff`, and `.patch`
- Local-first conversion without remote conversion services
