# MD2HTML Converter Privacy Policy

Effective date: July 2, 2026

MD2HTML Converter converts Markdown to HTML and HTML to Markdown in VS Code, Chrome, and Microsoft Edge. Conversion runs locally in the extension or editor webview. MD2HTML Converter does not send pasted, captured, converted, or edited content to Reallexi servers for conversion.

## Data Processed Locally

MD2HTML Converter may process the following data only to provide its conversion, preview, diff, copy, and export features:

- Markdown, HTML, selected text, selected page elements, or current page HTML that the user pastes, opens, selects, or captures.
- The current page URL or file name when it is needed to label captured content or choose a default output file name.
- Extension settings such as conversion direction, diff mode, theme, live conversion, and whether to remember the last input.
- Temporary mouse movement and click events while Mouse Reader is active, only to highlight and capture the page element selected by the user.

In the Chrome and Edge extensions, the most recent captured source and settings may be saved in local extension storage so the popup and side panel can continue the user's conversion session. This data remains on the user's device unless the user separately copies, downloads, exports, or shares it.

## Data Not Collected

MD2HTML Converter does not collect account identifiers, health information, payment information, authentication information, browsing history lists, location data, analytics events, advertising identifiers, or telemetry.

MD2HTML Converter does not sell user data, transfer user data to third parties, use user data for purposes unrelated to Markdown and HTML conversion, or use user data to determine creditworthiness or for lending purposes.

## Remote Code And External Services

MD2HTML Converter does not use remote JavaScript or remote WebAssembly. Extension code is included in the packaged extension. The Reallexi, GitHub Sponsors, and Buy Me a Coffee links open only when the user clicks them.

## User Control

Users can clear locally stored extension data by removing the browser extension or clearing extension site data in the browser. Users control what content is pasted, captured, copied, downloaded, or exported.
