# Real Memory AI Agent 1.6.606

Install the standalone CLI from [npm](https://www.npmjs.com/package/@reallexi/rmai/v/1.6.606) with `npm install --global @reallexi/rmai@1.6.606`. Run `rmai --version` to check the installation. See the [CLI README](../../cli/README.md) for usage.

The VS Code extension restores saved Scrum tickets on Continue. When Ollama repeats its response on a focused Writer ticket, it asks for one different approach in a separate advisory request before a bounded retry. Cancel waits for the owned work to stop before unlocking chat. A ticket still needs passing owned checks.
