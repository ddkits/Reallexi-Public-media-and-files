# Store copy — VS Code connected delivery wall

Track development on a scrolling Scrum board and connected Delivery map. Follow actual ticket dependencies across colored cards, see blocked prerequisites in red, and inspect the tasks each ticket blocks. Pan, zoom or Fit wall, then open notes, changed files and evidence from the selected ticket.

Fully delivered development tickets reach Done independently of final project testing. Feature acceptance and final completion still require validation evidence. Live indicators show observed agent activity; planned work alone does not animate.

Screenshots use sample data rendered in Chromium from the production VS Code webview. They are UI demonstrations, not a live model run. The map belongs to the VS Code product. Do not describe it as a native Chrome or Edge side-panel feature.

Use delivery-map-media.json for image paths, provenance and hashes. The VSIX README includes the map images for Visual Studio Marketplace and Open VSX. Live store submission requires the publisher's authenticated release environment; no live store update is claimed here.
