# Real Memory AI Agent Privacy Policy

**Effective date: October 26, 2026**  
**Publisher: Reallexi LLC**

This policy describes information handled by Real Memory AI Agent across VS Code, Chrome, Edge, CLI, MCP, and connected Real Memory services. The information involved depends on the surface, enabled features, permissions, task, and provider selected by the user.

## Information the product may handle

- Prompts, instructions, conversations, project requirements, and selected workspace source or configuration content.
- Command and validation output, diagnostics, changed paths, review records, task status, activity, and generated artifacts.
- Images or screenshots attached by the user or captured for requested visual evidence.
- For browser work, the active tab URL, title, visible text, links, headings, metadata, form labels, and requested screenshots or actions.
- Settings such as provider, model, endpoint, feature choices, and connection status, plus credentials needed to authenticate to a provider.
- Account and request information needed when the user signs in to or uses a Real Memory hosted service.

## Storage and processing

- **VS Code:** extension conversation and runtime records are kept in extension-managed storage on the user's device. Provider credentials use VS Code SecretStorage where supported.
- **Chrome and Edge:** sessions, settings, messages, activity, screenshots, artifacts, and evidence use extension-owned browser storage, including IndexedDB and browser local storage.
- **CLI and local MCP:** settings, sessions, runtime records, and generated evidence use the user or workspace locations configured for those tools.
- **Hosted services:** information sent to a Real Memory service is handled under the applicable service terms and account controls.

Local records remain until removed through available product controls or the containing application data is cleared. Storage controls vary by surface and version.

## Provider sharing

When the user submits a request, the product sends information needed for that request to the selected model provider or endpoint. This can include prompts, relevant source context, attachments, screenshots, browser context, and validation output. Authentication credentials may be sent in request headers. Supported configurations include user-controlled local, cloud, enterprise, Real Memory, and custom-compatible endpoints.

The selected provider controls its own logging, retention, training, and deletion practices. Review that provider's terms before sending sensitive content. Choosing a local model can keep inference on a user-controlled machine; it does not make every connected service or feature local.

## Sale, advertising, and website requests

Reallexi LLC does not sell, rent, or trade personal information collected through the product, and does not use it to build advertising profiles or target ads. Information may be shared with the selected provider or service to perform requested features and may be disclosed when required for legal, safety, or security reasons.

The static product information site does not include an analytics SDK, advertising pixel, or product sign-in form. GitHub Pages and a visitor's browser may process ordinary technical request information under their own policies.

## Controls and deletion

Use product controls for sessions, history, artifacts, and settings where available. Browser extension data can also be removed by clearing its local storage or uninstalling the extension. Use operating system or application controls to remove local VS Code or CLI data. For information held by a model provider or hosted service, use that provider's or service's deletion process.

## Sensitive information and children

The product is intended for developer and workplace use, not for children. Do not submit secrets, personal information, customer records, or regulated data unless your selected provider, endpoint, workspace permissions, and organization policies allow it.
